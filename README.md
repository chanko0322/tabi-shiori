## 写真の置き方（`src/` と `hero.jpg`）

- **`<しおり>/src/`** … 元の写真を入れておくフォルダ。撮ったままのサイズでOK
- **`<しおり>/hero.jpg`** … ヒーローエリアに表示される1枚。`src/` の写真から切り出して作る

`hero.jpg` が無いときは組み込みのSVGイラストが表示されるので、置くまでの間も
ページは崩れません（「壊れた画像」アイコンも出ません）。

いま設定されているヒーロー写真：

| しおり | 元写真（`src/`） | 切り出した内容 |
| --- | --- | --- |
| ハワイ 2017 | `LINE_ALBUM_201711 ハワイ旅行_250830_115.jpg` | ダイヤモンドヘッドと芝生（人物より上で切り出し） |
| ハワイ 2018 | `R0007320(1).JPG` | 夕暮れの溶岩台地とシルエット |
| シンガポール 2023 | `2023-11-03_21-09-20_370.jpeg` | 夜のマリーナベイと光のショー |

差し替えたいとき：

- `src/` に写真を足して「この写真にして」と言ってもらえれば、切り出して `hero.jpg` にします
- 自分で置く場合は、横長（幅1600px以上、横：縦＝2:1〜4:1くらい）のJPEGを `hero.jpg` として保存
- 表示は `object-position: center 42%` でトリミングされ、下半分に濃いグラデーションと文字が重なります。
  **人物のアップより風景の横長写真**が向いています（人が入る場合は小さく写っているもの）

富山のページも同じ仕組みにできます（現在はヒーロー画像をHTMLに埋め込み済み）。

## 各しおりページの構成

- ヒーロー（タイトル・日付。これからの旅はカウントダウン付き、過去の旅はなし）
- HIGHLIGHTS：見どころ／思い出のカード
- ITINERARY：日ごとのタブ＋ルートマップ＋タイムライン＋泊まりカード
- 右下に「行程へ」のフローティングボタン

HTMLは1ファイル完結（CSS・JS・イラストをインライン）で、外部リソースは
`hero.jpg` 以外読み込みません。
