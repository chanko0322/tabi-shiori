## ヒーロー画像（写真）の置き場

しおりのフォルダに **`hero.jpg`** という名前で写真を置くと、ヒーローエリアの背景が
その写真に切り替わります。ファイルが無いときは組み込みのSVGイラストが表示されるので、
置くまでの間もページは崩れません（「壊れた画像」アイコンも出ません）。

| しおり | 置き場所 | いまの状態 |
| --- | --- | --- |
| ハワイ 2017 | `2017-11-hawaii/hero.jpg` | 未設定（イラスト表示中） |
| ハワイ 2018 | `2018-11-hawaii/hero.jpg` | 設定済み（機窓から見たハワイ島） |

写真の目安：

- 横長（幅1600px以上、横：縦＝2:1〜3:1くらい）
- JPEG、500KB以下くらい
- 表示は `object-position: center 42%` でトリミングされるので、**人物のアップより風景の横長写真**が向いています
- 候補が複数あるときは `hero-1.jpg` `hero-2.jpg` などの名前で置いてもらえれば、こちらで選んで `hero.jpg` にします

富山のページも同じ仕組みにできます（現在はヒーロー画像をHTMLに埋め込み済み）。

## 各しおりページの構成

- ヒーロー（タイトル・日付。これからの旅はカウントダウン付き、過去の旅はなし）
- HIGHLIGHTS：見どころ／思い出のカード
- ITINERARY：日ごとのタブ＋ルートマップ＋タイムライン＋泊まりカード
- 右下に「行程へ」のフローティングボタン

HTMLは1ファイル完結（CSS・JS・イラストをインライン）で、外部リソースは
`hero.jpg` 以外読み込みません。
